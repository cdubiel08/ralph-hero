## Advisory notes (non-blocking)

1. **Citation drift on parent line range**: the child plan's `Implementation Approach` cites parent lines 360-369 for Step 10's final-report shape; the actual fenced markdown for Step 10 ends at line 368 with the closing code-fence at 369. Off by zero — the citation is fine if read inclusive of the closing fence. Not worth a re-issue.

2. **Task 1.2 acceptance row count phrasing**: Task 1.2's fourth acceptance check refers to "the canonical 5-row termination-conditions table" but then enumerates 6 rows (1-5 plus the `(else) → CONTINUE` catch-all). The R3 critique of the parent plan explicitly added the `else` row as a 6th catch-all (parent line 329); the child plan's enumeration is correct, only the prefix word "5-row" lags. Equivalent fix: change "5-row" to "5-condition + catch-all" or "6-row including the else catch-all." Cosmetic; the implementer reading the enumerated list will produce the right table either way.
