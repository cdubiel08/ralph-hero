# Plan Critique: GH-0726 (Group with #727, #728)

## Summary

This is a Phase 2-of-3 atomic group plan covering three sibling issues (#728, #726, #727)
under parent epic GH-725. All three issues add prose-only knowledge-graph awareness to the
ralph-hero research workflow. The plan is well-structured, lines up cleanly with the
canonical references it cites, and uses the `prove-claim` patterns it borrows from
faithfully. Recommendation: **APPROVED** — the plan is ready for implementation. A few
minor observations are recorded below for the implementer; none are blocking.

- No SessionStart/PreToolUse/PostToolUse/Stop hook modifications.
- No `plan` or `ralph-plan` skill changes.

- No version bump expectation (skills-only changes shouldn't trigger auto-release).

Each exclusion is paired with a one-line rationale, which makes scope decisions
auditable. The grouping of three issues into one PR is justified explicitly: shared
prose patterns + dispatch chain (skills dispatch sub-agents → strengthen sub-agents
first → then teach skills to use them).
