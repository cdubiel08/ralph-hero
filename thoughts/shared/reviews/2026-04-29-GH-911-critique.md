## Minor Observations (Non-Blocking)

These are notes for the implementer; none warrant iteration:

1. **Task 3.4 says "do NOT commit any probe"** — good; ensures the verification probe is local-only. The implementer should avoid leaving stray files under `dist/` that could be committed accidentally.
2. **Task 3.3 sets `RALPH_CONTEXTUAL_RETRIEVAL=0`** — consistent with the GH-910 baseline. The plan should consider running once with default contextual retrieval after the OOM fix lands, but flagging this as future work is acceptable; it's not part of the immediate verification scope and is implicitly covered by sibling work.
3. **Phase 3 backup/restore (Tasks 3.1 / 3.6)** — the safety guardrail around `~/.ralph-hero/knowledge.db` is a good practice given that a fresh reindex rewrites the DB. The acceptance criterion correctly requires a sqlite3 healthcheck before keeping the new DB.
4. **Test count assertion ("32 tests in `embedder.test.ts`")** — Phase 1 acceptance lists "Existing 32 tests…continue to pass". If the actual count drifts before implementation begins, this should be relaxed to "all existing tests" rather than treated as a strict number. Minor footnote.
