## Recommended Changes

Optional strengthening edits, not blockers — the implementer should address these:

- **`??` vs `||` empty-string edge case.** With `??`, an explicit `workflowState: ""` is *not* nullish, so it flows to `updateProjectItemField("", ...)` and throws — whereas today `if (args.workflowState)` silently skips it. Fringe input; add a one-line Migration Notes mention ("empty-string state now errors instead of silently skipping; use omission to get the Backlog default").
- **Strengthen the default-path test assertion.** Also assert the `syncStatusField` mutation fired for `Status → Todo`, since that is the observable "board item" side of the default and exercises the newly-unconditional `syncStatusField` call.
