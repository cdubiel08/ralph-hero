## Feasibility

- **Phase 1**: Two-line frontmatter change. The hero orchestrator proves this pattern works. The finish skill already has `SessionStart` hooks that set `RALPH_COMMAND=finish`, which will fire correctly in inline mode (hero uses the same pattern). Risk: minimal.
- **Phase 2**: Single-line change adding `timeout 10` prefix. The `|| exit 0` already handles failure, so timeout exit code (124) is caught by the same fallback. macOS ships `timeout` via coreutils (available if installed via brew) -- however, macOS does not include `timeout` by default. The plan should note this, but since the `|| exit 0` makes it non-fatal, the worst case is the command not being found and the hook exiting cleanly. Acceptable.
- **Phase 3**: Single-row table addition. Documentation-only, no runtime impact.

## Minor Notes

- Phase 2 assumes `timeout` is available on the system. On macOS, this requires GNU coreutils (`brew install coreutils`). However, since `|| exit 0` catches any failure including command-not-found, this is non-blocking. A `gtimeout` fallback or `LANG=C command -v timeout` guard would be belt-and-suspenders but is not required for an XS fix.
