## Notes / non-blocking observations

- **Task 5.3 manual-test cost**: the Manual Verification section requires a running `mlx-openai-server` on an M5 Pro and a live Tailnet to fully verify. Phase Success Criteria → Automated is sufficient for CI gating; Manual gating is the operator's call. Plan is honest about this (line 161: "Streamlit apps are notoriously hard to unit-test").
- **`knowledge_search` binary path** (Task 5.3, line 279): the `_call_mcp` helper accepts an optional `binary_path` argument so Panel 6 can target the ralph-knowledge MCP binary rather than ralph-hero's. The plan acknowledges these are two separate binaries. The implementer must take care to pick the right one per panel — recommend a 1-line helper assertion would tighten this, but it is not a blocker.
- **`pyproject.toml` `httpx` dep** (Task 5.1, line 199): listed as "optional — only if MCP client uses async HTTP; otherwise omit." Given `_call_mcp` is a synchronous one-shot via `subprocess`, `httpx` is unnecessary. Implementer can safely omit. Non-blocking.
- **File-length budget** (Task 5.3, line 299): "≤ 600 lines" target for `app.py`. With six panel render functions + chat + `_call_mcp` helper + main + imports + constants, 600 lines is generous but achievable. If the implementer trends over, the plan's escalation path is reasonable.
