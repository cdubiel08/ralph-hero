Every phase's success criteria asserts `bash ralph/skills/shared/__tests__/*.test.sh` passes — impossible after Phase 1 unless that test is also edited. The plan never names this test file as a file to change, and "What We're NOT Doing" says nothing about it. (Note: that test file already shows as `M` in `git status` — the plan should reconcile with whatever in-flight edit exists there.)
- **Verification quality (minor)**: Phase 1's `grep -n 'hero:default' loop-wrapper.md returns no loop-suitable manifest row (or only a not-a-loop-target note)` is not a runnable pass/fail assertion — `grep` returning a note line still exits 0, so a human must eyeball it.
