# Ralph Pipeline Status

Display the current pipeline status dashboard.

## Use When

Use this skill when the user asks for the **raw pipeline view, dashboard snapshot, or board status** — phrasings like "show me the pipeline", "what's on the board?", "give me the dashboard", "status report" (without posting), or "list everything in flight". The output is a structured table generated by the MCP layer; this skill surfaces it unchanged.

Do **not** use this skill for:

- **Conversational orientation** ("what should I work on next?", "catch me up", "anything on fire?") — use `hello` instead. `hello` synthesizes memory + dashboard + open PRs into a 3-direction briefing tuned for session-start.
- **Posting a status update to GitHub Projects** — use `report` instead. `report` composes a stakeholder-facing markdown report and writes it via `create_status_update`.

This skill is read-only and never adds commentary beyond the rendered dashboard plus any critical-severity health warnings.

## Usage

Fetch the pipeline dashboard with the requested format:

1. Parse the argument (if provided) as the output format. Default to `markdown`.
2. Fetch the pipeline dashboard with:
   - `format`: parsed format or `"markdown"`
   - `includeHealth`: true
   - `issuesPerPhase`: 5
3. Display the `formatted` field (for markdown/ascii) or the structured data (for json).
4. If health warnings exist with severity `critical`, highlight them prominently.

## Output

Display the dashboard output directly. Do not add additional commentary unless there are critical health warnings.
